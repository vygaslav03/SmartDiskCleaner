# Smart Disk Cleaner

[English version](README.md) · [Скачать .exe](https://github.com/vygaslav03/SmartDiskCleaner/releases/latest)

Безопасная локальная утилита очистки диска для Windows 10/11 на Python 3.12 + PySide6.
Собирается в один `DiskCleaner.exe`, который запускается на любом Windows-ПК без установленного Python.

**Главный принцип: программа никогда не удаляет файлы без явного подтверждения пользователя.**

## Возможности

| Раздел | Что делает |
|---|---|
| **Обзор** | Диск (Total / Used / Free), кнопки «Сканировать» и «Smart Clean», итоги последнего сканирования и очистки |
| **Очистка** | Мусор по категориям с чекбоксами, количеством и размером; «Выбрать всё», «Снять всё», «Подробнее» — полный список файлов, где можно снять галочку с отдельных файлов, чтобы они не удалялись |
| **Smart Clean** | Сам отмечает только безопасные категории (temp, кэш, миниатюры, crash dumps, корзина) и **всегда** показывает список перед удалением |
| **Анализ диска** | Интерактивная карта занятого места (treemap: клик — выделить, двойной клик — зайти внутрь), синхронизированная с деревом папок, отсортированным по размеру, с полосками доли и самыми большими файлами в каждой папке. Только просмотр; кнопка «Найти большие файлы здесь» открывает поиск в выбранной папке |
| **Большие файлы** | Поиск файлов > 100 MB / 500 MB / 1 GB / 5 GB / 10 GB: имя, полный путь, размер, дата. Удаление — только по отдельному подтверждению с галочкой «я проверил список» |
| **Дубликаты** | Поиск в Загрузках, Рабочем столе, Документах, Изображениях, Видео: размер → частичный хеш → полный BLAKE2b. В каждой группе обязательно остаётся минимум одна копия |
| **Карантин** | Очищенный мусор сначала переносится в папку карантина (тот же диск, мгновенно) и хранится 7 дней — его можно восстановить одной кнопкой. Восстановление никогда не перезаписывает существующие файлы. Место освобождается по истечении срока или вручную |
| **История** | Итоги всех очисток: дата, тип, диск, сколько удалено и освобождено, сколько не удалось; общий итог «освобождено всего». Хранится в `history.json`, пути файлов не записываются |
| **Настройки** | Язык (RU / UK / EN), тема (системная / тёмная / светлая), пороги, исключения, режим удаления (Корзина / навсегда) |

### Категории мусора

* **Windows:** `C:\Windows\Temp`, кэш Windows/шейдеров (INetCache, D3DSCache, NVIDIA/AMD/Intel), кэш миниатюр, crash dumps (CrashDumps, Minidump, MEMORY.DMP), кэш Windows Update (`SoftwareDistribution\Download`), Delivery Optimization.
* **Временные файлы:** `%TEMP%`, `%LOCALAPPDATA%\Temp` (файлы моложе 24 ч не трогаются — их могут использовать установщики).
* **Браузеры:** Chrome, Edge, Brave, Opera/Opera GX, Firefox — **только папки кэша** (Cache, Code Cache, GPUCache, cache2…). Cookies, пароли, история, сессии и закладки не затрагиваются.
* **Приложения:** Discord, Telegram Desktop (только медиа-кэш, не `tdata`), Steam (httpcache, htmlcache, дампы, логи), VS Code, Spotify, pip/npm/NuGet/Yarn.
* **Логи:** отчёты Windows Error Reporting, старые системные логи (`C:\Windows\Logs`), старые логи приложений.
* **Корзина:** через Windows API `SHQueryRecycleBinW` / `SHEmptyRecycleBinW`.
* **Системные операции Windows** (только с правами администратора, только явным выбором — не входят в Smart Clean и «Выбрать всё»):
  * `Windows.old` — удаляется встроенной «Очисткой диска»: `cleanmgr /sagerun` с включённым только пунктом «Предыдущие установки Windows»;
  * очистка хранилища компонентов — `DISM /Online /Cleanup-Image /StartComponentCleanup` **без** `/ResetBase` (обновления остаются удаляемыми).
  Эти файлы принадлежат TrustedInstaller, поэтому программа не удаляет их сама, а вызывает штатные инструменты Windows.

**Правила Winapp2.ini (по желанию).** В «Настройках» можно импортировать скачанный вами
[winapp2.ini](https://github.com/MoscaDotTo/Winapp2) — открытую базу правил очистки для сотен программ.
Программа его не скачивает (работает без сети) и хранит копию рядом с настройками.
Поддерживаются только правила для файлов (`FileKey`, `ExcludeKey`, `Detect`, `DetectFile`, `SpecialDetect`);
`RegKey` (очистка реестра) игнорируется. Пути принимаются только с переменными
`%LocalAppData%`, `%AppData%`, `%LocalLowAppData%`, `%ProgramFiles%`, `%CommonAppData%`, `%WinDir%`,
`%UserProfile%`, `%SystemDrive%`; пользовательские папки и абсолютные пути пропускаются. Каждое правило
проходит те же проверки безопасности, что и встроенные; правила для неустановленных программ не показываются;
импортированные категории не входят в Smart Clean. Если правило дублирует встроенную категорию,
файл показывается только во встроенной. Проверьте лицензию Winapp2 перед распространением файла вместе с программой.

Перед очисткой программа проверяет, не запущены ли Chrome, Edge, Firefox, Discord, Telegram, Steam и др.
Процессы **не закрываются принудительно** — пользователь сам закрывает их и нажимает «Проверить снова»
или пропускает эти категории.

## Безопасность

Программа работает по **белому списку**. Файл будет удалён, только если выполнены все условия
(см. `app/core/safety.py`):

1. Файл найден **этим** сканированием. Произвольный путь передать на удаление нельзя.
2. Путь абсолютный, без `..` и NUL — защита от path traversal.
3. После раскрытия symlink / junction / 8.3-имён путь не изменился (через ссылку нельзя выйти за пределы папки).
4. Это обычный файл: не папка, не reparse point, без атрибута SYSTEM; не `pagefile.sys`, `hiberfil.sys`, `ntuser.dat`, `*.sys` и т.п.
5. Файл подпадает под конкретное правило своей категории (папка + маска; нерекурсивные правила вроде `MEMORY.DMP` разрешают только файл с этим именем прямо в этой папке).
6. Файл не лежит в защищённой зоне: Desktop, Documents, Downloads, Pictures, Videos, Music, OneDrive,
   `System32`, `SysWOW64`, `WinSxS`, `Installer`, Program Files (без отдельного разрешения в настройках),
   `System Volume Information`, `$Recycle.Bin` и пользовательские исключения. Реальные пути
   пользовательских папок берутся через `SHGetKnownFolderPath`, поэтому учитываются перенесённые папки.
7. Размер и дата изменения совпадают с данными сканирования (файл, изменившийся после скана, пропускается).

Сами правила тоже проверяются: корень правила не может быть корнем диска, профилем, AppData целиком,
`C:\Windows` целиком и т.п.

Дополнительно:

* сканер никогда не заходит в symlink/junction;
* занятые файлы (`ERROR_SHARING_VIOLATION`), Access Denied, слишком длинные пути (используется префикс `\\?\`) обрабатываются и просто пропускаются — ошибка одного файла не останавливает операцию;
* после удаления убираются только **опустевшие** подпапки внутри правил, корень правила — никогда;
* большие файлы и дубликаты по умолчанию отправляются **в Корзину** (можно восстановить);
* файлы OneDrive «только в облаке» не читаются при поиске дубликатов (иначе Windows начнёт их скачивать).

### Права администратора

Программа запускается **без** прав администратора. Они нужны только для системных категорий
(`C:\Windows\Temp`, Windows Update, Delivery Optimization, системные логи). Такие категории помечены
значком щита; при попытке их очистить программа объяснит причину и предложит перезапуск через UAC
или продолжение без них.

### Приватность

Всё выполняется локально. Нет телеметрии, рекламы, аккаунтов, облака и автообновления. Имена файлов,
пути, хеши, системная информация и логи никуда не отправляются. Программа не открывает сетевых соединений.
В лог не пишется содержимое файлов.

## Требования

* Windows 10 или 11 (x64)
* Для запуска из исходников и сборки: Python 3.12+ (https://www.python.org/downloads/ — при установке отметьте «Add python.exe to PATH»)
* Для готового `DiskCleaner.exe` Python не нужен

## Установка и запуск из исходников

```bat
cd F:\APP\cleaner
python -m venv .venv
.venv\Scripts\activate
python -m pip install --upgrade pip
pip install -r requirements.txt -r requirements-dev.txt
python run.py
```

## Самопроверка интерфейса

`selftest.bat` открывает все страницы, выполняет реальные операции только чтения
(сканирование, анализ диска, поиск больших файлов и дубликатов в тестовой папке) и
сохраняет скриншоты и `selftest\report.txt`. Удаление в этом режиме заблокировано.

## Тесты

```bat
.venv\Scripts\activate
python -m pytest
```

Без pytest тоже можно: `python -m unittest discover -s tests -t .`

Тесты работают **только во временных папках** (`tempfile.mkdtemp`) и никогда не трогают реальные
системные директории. Тесты на symlink автоматически пропускаются, если в Windows не включён режим разработчика.

## Сборка .exe

```bat
build.bat
```

Скрипт сам создаст `.venv`, установит зависимости, прогонит тесты и запустит PyInstaller:

```
pyinstaller --noconfirm --clean --onefile --windowed --name DiskCleaner --icon assets\icon.ico ...
```

Готовый файл: **`dist\DiskCleaner.exe`** — его можно передавать друзьям.

### Иконка

`assets\icon.ico` — временная заглушка. Замените файл своим `.ico` (16/32/48/256 px) с тем же именем
и пересоберите `build.bat`.

## Где программа хранит данные

* `settings.json`, `history.json` и `logs\app.log` — рядом с программой (портативный режим);
* если туда писать нельзя (например, exe лежит в Program Files) — в `%LOCALAPPDATA%\DiskCleaner`.

Лог ротируется (5 файлов по 2 МБ). Записываются: запуск, начало сканирования, найденные категории,
ошибки, начало удаления, результаты удаления.

## Как добавить свою категорию

В `app/core/categories.py` добавьте `CategoryDef` с правилами `RuleSpec("{LOCALAPPDATA}\\MyApp\\Cache")`
и строки `cat.<id>` / `cat.<id>.desc` в `app/utils/i18n.py`. Тест `test_every_rule_resolves_safely`
проверит, что правило проходит проверки безопасности.

## Известные ограничения

* Файлы, занятые запущенными программами (браузер, Discord, Проводник для миниатюр), пропускаются — закройте программы перед очисткой.
* Категории C:\Windows требуют прав администратора; без них они показываются, но не очищаются.
* Сканирование мусора идёт по папкам выбранного диска. Почти весь мусор Windows лежит на системном диске; для других дисков обычно находится только корзина.
* Удаление происходит по списку из сканирования: файлы, появившиеся после него, не удаляются (нужно пересканировать).
* Поиск больших файлов и дубликатов не заходит в Windows, Program Files, ProgramData и AppData.
* Жёсткие ссылки не считаются дубликатами; файлы OneDrive «только в облаке» пропускаются.
* Корзина очищается целиком для выбранного диска (так работает Windows API); список её содержимого — только для просмотра.
* Onefile-сборки PyInstaller иногда ложно помечаются антивирусами/SmartScreen. Если это мешает, соберите вариант папкой: замените `--onefile` на `--onedir` в `build.bat` (результат — `dist\DiskCleaner\DiskCleaner.exe`).
* Смена языка применяется после перезапуска программы.
* Сколько места освободит DISM, заранее неизвестно — после очистки показывается фактически освобождённое место (по изменению свободного места на диске). Прервать DISM нельзя.
* Анализ диска считает логический размер файлов: сжатые NTFS-файлы и жёсткие ссылки (например, в WinSxS) могут давать сумму больше реально занятого места. Папки без доступа не учитываются — для полной картины запустите от администратора.
